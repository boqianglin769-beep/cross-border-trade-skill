# 法规库索引（Regulation Library Index）

> 本目录存放各目的国/地区海运进口与清关主体规则、产品准入法规，供报价前核实使用。
> **时效性声明**：本库内容以 `last_verified` 标注的检索日为界确认；外国法规可能随时修订，**正式报价前必须重新核实目标法规的现行有效状态与最新修订**，并记录核实时点。

## 使用规则

1. **查表顺序**：确认目的国 → 打开对应国家文件 → 核对"上门到港/到门"、"清关主体"、"特殊限制"三栏 → 再查 `products.md` 中产品所属品类的准入要求。
2. **必标依据**：Skill 输出报价单时，涉及法规判断的部分在报价单"备注/合规说明"栏**简要提及法规名称**（如 `据 IN RFB 1.984/2020 属巴西清关主体要求`），完整法条仅保存在本库与内部工作底稿，不写入客户报价单。
3. **时效复核**：报价单发出前，对引用法规执行一次 freshness 复核（websearch 官方源），并在报价工作底稿中记录 `核实日期 + 法规现行状态`。
4. **冲突处理**：本库内容与最新官方公告冲突时，以官方最新文本为准，并回写更新本库。
5. **未确认项**：标注 `[待核实]` 的条目不得作为报价依据，必须在报价前补充确认或明确告知客户不包含该判断。
