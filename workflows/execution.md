# Workflow: 订单履约与出口执行全流程（Order Execution & Export Compliance）

## Purpose

现有工作流覆盖「询价 → 法规核实 → 报价 → 汇报 → 催单」。本工作流补齐**报价成交后的整条履约执行链**：

> 下单前准备 → 下单生产中 → 生产完成 → 装柜与出口报关 → 目的港清关 → 出口退税

数据来源：公司内部《外贸流程以及注意要点》。**所有客户/工厂/货代名称、地址、账号、单据编号、金额均以占位符呈现**，实际使用时替换为真实信息；不得将真实主体、底价、账号写入对外文档或对话侧。

## Trigger

用户说：「下单」「生产」「包装设计」「检测」「验货」「排柜」「装柜」「报关」「清关文件」「ISF」「退税」「履约」「出货流程」「全流程执行」。

---

## 阶段总览

| 阶段 | 关键动作 | 交付/留档 | 常见坑 |
|------|----------|-----------|--------|
| 一 · 下单前 | 产品合规预审、细节确认、工厂采购合同、报价 | 定制细节书 / 采购合同 / 报价单 | 版权、HS 错、税点未确认 |
| 二 · 下单生产中 | 外包装设计、产品检测认证 | 包装设计稿 / 检测证书 | 警示语不合规、送检不含外包装 |
| 三 · 生产完成 | 线下验货、排柜、装柜信息对接 | 产品检测资料表 / 排柜方案表 | 用产品裸尺寸、多工厂装柜顺序乱 |
| 四 · 装柜与出口报关 | 装柜拍照、提单补料 SI、报关 | 装柜照片 / SI / 报关单 | 单货不一致、SI 重量误差 >5% |
| 五 · 目的港清关 | 清关文件、ISF | B/L / 箱单 / 发票 / ISF | 三单不一致、放单前未收全款 |
| 六 · 出口退税 | 退税材料、发票、汇率 | 完整证据链 | 资料不全、汇率取错月份 |

> 核对清单与表单模板见 `templates/execution-checklist.md`。

## 一、下单前（Pre-Order）

### 1.1 产品信息与合规预审

- **版权先行**：首次对接产品须优先确认产品**版权归属**，避免侵权风险（玩具、贴牌、卡通形象尤其注意）。
- **检测/认证**：若产品有检测/认证证书，核实**证书有效性、适用国家/地区**，留存证书原件。
- **基础参数 + 税点**：同步确认产品基础参数与**税点**，为后续报价、定制做铺垫。

### 1.2 确认最终产品细节

- 涉及**颜色变更、Logo 印制**等定制时，先出一份**最终产品定制需求细节书**，双方确认后再打样。
- 咨询产品 **HS Code**，并确认**工厂能否开对应 HS Code 类目的增值税发票**。
- 按《产品明细表》格式整理给报关员，报关员据此给出**海关码参考**（见 `templates/execution-checklist.md` 附表一）。

### 1.3 与工厂签订采购合同

合同须明确、无模糊表述：

- 定制要求、装箱规格、交期、质量标准、验收方式；
- 付款比例（定金/尾款节点）与收款信息；
- 工厂完整信息（避免付款失误）：公司全称、注册地址、联系人、联系电话；收款账号、账户名、开户银行（**支行级别**）。

### 1.4 面向客户报价

- 向工厂咨询**定制费、检测费、认证费、包装费**等所有额外费用，**提前平摊计入客户报价**，避免后期争议。
- 报价单明确**贸易术语（FOB/CIF 等）、起运港、付款方式、交期**，标注**报价有效期**。
- 具体执行见 `workflows/quotation.md`。

## 二、下单生产中（In Production）

> 本阶段要点**重点针对出口美国产品**；其他国家需提前查询当地最新标准，按对应要求执行。各国准入规则另见 `regulations/products.md` 与对应国家文件。

### 2.1 外包装设计

**基础信息**：产品名称、二维码、条形码。基础信息需客户提供的材料，应尽快与客户确认再进行包装设计。

> 留意：同一款产品**外箱条形码与产品条形码可能不同**；新客户若有外箱条形码要求，须单独确认。

#### 2.1.1 产品外包装

- 外观设计风格按客户要求 / 外贸部自行设计。
- **玩具类外包装**注意：
  - 标注**年龄范围、玩具小零件警示语、防窒息标识**（若有较大产品袋）；
  - 警告语包含「危险类型 + 危险源 + 年龄限制」，典型表述：`WARNING: Choking hazard - Small parts. Not for children under 3 years.`
  - 「WARNING」需**突出显示**（加粗/变色/下划线），位于产品主展示面板；
  - 3–6 岁儿童玩具含小部件的警示语：`WARNING: CHOKING HAZARD - Small parts. Not for children under 3 yrs.`
  - 标注产品已有的检测/认证（如美国 ASTM F963 等）；
  - 若内含电池需标注；
  - 涉及史莱姆、放屁泥等含化工材料产品，需标注**配料成分**（参考已出货产品的包装文字）。
- **美国 CPSC 对小零件警告语的规范**：核心原则是警告必须**清晰易读、位置醒目、语言直接**；含小零件玩具必须标注窒息风险警告；「WARNING」需突出显示，警告语须包含危险类型（Choking hazard）、危险源（Small parts）与明确年龄限制；气球类产品有更严格要求：`WARNING: CHOKING HAZARD - Children under 8 yrs can choke or suffocate on uninflated or broken balloons. Adult supervision required.`（详见 `regulations/products.md`。）
- 出口其他国家需提前查询、咨询确认。
- **出口美国**：新产品送检时，**新产品连带外包装需一并送检**；美国对包装设计字体大小有要求，字号适中、清晰，具体字号咨询检测机构。

#### 2.1.2 大外箱设计

客户无特殊外箱正侧唛排版要求时，按标准模板设计外箱。

- **正唛必备**：产品名、一箱产品数、客户编号（如有）、客户 Logo、毛重（G.W.）、净重（N.W.）、外箱尺寸（MEAS.）、MADE IN CHINA；
- **侧唛必备**：毛重、净重、外箱尺寸；
- **特殊标注**：
  - 外箱条形码由**客户提供**，确认后再印制；
  - 内含电池的产品，外箱**强制标注电池标识**（常规为 UN3481，特殊电池需提前与报关员确认标识）；
- 设计完成后**复核所有信息**，避免错标/漏标。

### 2.2 产品检测与认证

产品出口前须提前查询出口国对应产品的**强制检测/认证要求**；不同产品、不同年龄段检测内容侧重不同，提前与机构或工厂沟通。

**美国**常见所需证书：

| 证书 | 适用范围 | 备注 |
|------|----------|------|
| ASTM F963-23 | 14 岁以下儿童玩具 | 23 年最新标准；后续按最新规定更新 |
| CPSIA | 不超过 12 岁的儿童 | |
| 微生物 / TRA / 防腐 | 常见于史莱姆、泡泡水等化工材料 | 三份证书检测周期较长，如有要求提前送检/更新 |
| 电池检测证书 | 含电池产品 | UN38.3 / 海运 / MSDS、一般可直接用工厂提供的证书 |
| CPC 证书 | 玩具产品 | 完成 ASTM F963-23、CPSIA 后出具；需向工厂提供**美国进口商信息** |

- **CPC 证书**：需填写美国进口商信息（Name / Address / Contacts / Phone / Email）、制造商信息、产品型号与生产日期；若客户要求以客户公司名义，须将**最终确定的产品 + 外包装**送检，并提供客户信息与最终产品信息给检测中心。
- **严格核对证书上的产品信息**（品名/规格/型号），确保与实际产品一致；注意**避开版权问题**。
- 检测中心须与有**国际认证资质**的检测认证机构合作；美国资质检测认证机构可在 CPSC 官网查询：`https://www.cpsc.gov/cgi-bin/LabSearch/default.aspx`。

## 三、生产完成（Production Complete）

### 3.1 线下验货

- 大货全部完成后安排线下验货，以**采购合同 + 定制细节书**为验收标准，重点检查产品质量、规格、定制要求是否达标。
- **关键操作**：重新**实测大货的外箱尺寸、产品尺寸、毛重、净重**——该数据为后续订舱、报关、制单的**唯一依据**，填写《产品检测资料表》留存（见 `templates/execution-checklist.md` 附表二）。
- 检测项目示例：外观检测 / 仿真度与误导性 / 小部件检查 / 活动部件检查 / 尖锐边缘与毛刺检查 / 电子功能检测 / 连接部位检查 / 组装与拆卸便携性 / 拉力与压力测试 / 包装与标识检查。

### 3.2 排柜

- 根据**集装箱柜型（20GP/40GP/40HQ）、产品外箱尺寸、生产工厂地址**，制定最优排柜方案，安排装柜地址，最大化利用柜容。
- **多工厂供货**：按工厂地址**就近原则**规划装柜顺序，减少拖车运输成本和时间。
- 排柜方案确认后，同步告知**工厂、货代、装柜人员**具体装柜要求，避免装柜时货量不符、摆放混乱。
- **含电池/易碎/特殊产品**：单独规划摆放位置，做好防护，标注在排柜方案中并告知装柜人员。
- **仓库内装对接**：如由货代提供仓库并在仓库内装柜，提前咨询货代**仓库地址、入仓要求、入仓时间**，与工厂对接安排运输车辆，按货代要求填写**《入仓单》**，确保按时入仓。

### 3.3 装柜信息

#### 3.3.1 对货代

- **订舱信息同步**：将《排柜方案表》+ 货物基础信息（总货量、总毛重、总体积、起运港、目的港、交期）发送货代，明确**订舱要求、截关时间、开船时间**；
- **特殊产品提前报备**：含电池/化工/玩具等特殊品类，提前明确告知货代，确认**船司是否接受**此类货物，避免订舱后无法走货；
- **电池产品额外要求**：提前咨询货代是否需要 **UN38.3、MSDS**、是否需填写**锂电池非危保函**，按要求准备提交；
- **订舱单（SO）获取与核对**：货代订舱后及时索要 SO，重点核对**柜型、起运港、目的港、截关/开船时间、柜号、封号**，有误立即要求修改；
- **日常对接**：装柜前同步装柜时间、地点；装柜完成后及时发送装柜信息，跟进报关、提柜、上船进度；出现物流异常（截关延误、船期变更）立即沟通；
- **费用**：不同成交方式的货代费用支付方不同，需提前确认。

#### 3.3.2 对工厂

- 与货代确定装柜信息后，及时把**装柜时间、装货地点、订舱号、柜号、封号、柜型、拖车车牌号、司机姓名及手机号**完整同步给工厂；
- 提醒工厂提前备货，按排柜方案整理货物，特殊产品做好防护，确保拖车到厂后可立即装柜；
- 与工厂确认**装柜对接人**，确保装柜过程沟通顺畅。

> 催货代、催工厂话术见 `templates/follow-up.md`。

## 四、装柜与出口报关（Loading & Export Declaration）

### 4.1 装柜

装柜需**全程拍照留证**（留存至订单退税、客户清关完成），便于后续异常核查，避免货损、货差争议。

#### 4.1.1 装柜前准备

- 提前与拖车公司确认**拖车到厂时间**，通知工厂做好装货准备；
- 核对**拖车车牌号、集装箱柜号、封号**，与 SO 信息逐一匹配，不一致立即联系货代；
- 检查集装箱内部：确保无漏光、破损、污渍、积水，异常及时拍照并联系货代处理，**严禁使用问题集装箱**。

#### 4.1.2 装柜拍照（9 步）

1. 拍摄**集装箱车牌号**，与预定信息核对存档；
2. 拍摄**集装箱柜号**（箱体显眼位置），确认与 SO 一致；
3. 拍摄**空柜整体照片 + 侧面柜号照片**，清晰展示空柜状态；
4. 进入集装箱内部，拍摄**内箱全景照**，检查是否漏光、破损、异物；
5. 货物装至一半时，拍摄**半柜照片**，记录摆放位置、堆叠方式，确保符合排柜方案；
6. 货物装完后，拍摄**满柜照片**，展示最终摆放状态，确认无空隙、无倾倒风险；
7. 拍摄**右门关闭后**照片，清晰显示门封状态；
8. 拍摄**左门关闭后**照片，确保柜门完全关闭；
9. 拍摄**封条近距离清晰照片**，确认封条号与 SO/预定信息完全一致，封条完好无破损。

#### 4.1.3 提单补料（SI）

**定义**：提单补料（Shipping Instructions，SI）是托运人向船公司或货代提供的货物及运输相关信息，用于正式签发海运提单（B/L）。

**包含内容**：① 发货人信息；② 收货人信息；③ 通知方信息；④ 货物详情（名称、件数、毛重、体积、HS 编码、包装类型）；⑤ 运输信息（起运港、目的港、船名航次、集装箱号、封号）；⑥ 运费条款（预付/到付）。

**操作流程**：① 货代/船公司发出补料格式要求 → ② 托运人按要求填写（须与信用证、合同一致）→ ③ 提交后，货代/船公司回复**补料确认件（Draft B/L）**，托运人逐项核对无误。

**注意要点**：

- **截止时间**：通常注于预配或 SO；**近洋航线一般为截关当天，远洋航线为截关前 2 天**，须严格遵守；
- **语言要求**：所有补料必须提供**英文版本**；
- **重量误差**：补料填写的货物重量与实际过磅重量**误差不得超过 5%**，否则可能影响运输安排或产生额外费用；
- **信息核对**：核对各项信息及提单类型，确保与实际业务和需求相符；
- **编码使用**：补料编码一般使用**国内编码**，遵循国内相关编码规范；
- **信息变更同步**：若货物**实装数量、毛净重与排柜方案有出入**，第一时间制作**《实际装柜清单》**，同步货代并修改 SI，确保补料与实装一致；
- **补料留存**：留存补料提交记录、货代确认回执。

> ⚠️ SI 数据直接影响正本/电放提单的准确性，填报时须**逐字核对**；不同货代补料模板不同，参考模板即可。

#### 4.1.4 注意

货物实装与排柜方案有出入时，及时同步《实际装柜清单》，SI 也须及时修改后提交货代。装柜完成后让司机及时**过磅**获取**过磅单**（若临近船司截关无法过磅，需留存**情况说明**）。

### 4.2 报关（截关前必须确认完）

整理报关材料，提交给报关员即可。

#### 4.2.1 报关材料（一柜一单）

按对应装柜的**柜号、SO 号**准备；出口产品为普货时，所有资料按「个」为最小单位制单：

1. 外贸购销合同（与客户签订的正式合同）；
2. 商业发票 CI（与实际成交金额一致，标注产品明细、HS 编码）；
3. 装箱单 PL（按《实际装柜清单》制作，标注品名/规格/数量/毛净重/外箱尺寸）；
4. 产品明细表（含最终核定的 HS 编码）；
5. 订舱单（SO）及附件；
6. 申报要素表（按 HS 编码完整填写海关要求的申报要素：品名、规格、材质、用途、品牌等）；
7. **特殊产品附加资料**：电池类（UN38.3、锂电池非危保函、MSDS）、玩具类（CPC / ASTM F963-23 / CPSIA）、化工类（微生物/TRA/防腐检测报告）；
8. 拖车司机信息、过磅单（如有）。

> 报关文件数据要和最后装柜实装数据一致；**客户如为美国 LLC（有限责任公司），也需自行报关**。

#### 4.2.2 报关注意

1. **单单一致、单货一致**：所有报关资料的品名、规格、数量、毛净重、体积、HS 编码、柜号/封号必须完全一致，且与实际装柜货物匹配；
2. **HS 编码准确**：严格按最终核定的 HS 编码填报，不得随意变更，避免归错码导致查验、退税异常；
3. **申报金额规范**：按实际成交金额如实申报，不得低报、高报；
4. **数据精准**：所有数字（数量/毛净重/体积）须与《实际装柜清单》、过磅单一致，单位统一（毛净重 KG、尺寸 CM）；
5. **合同协议号**：报关单中的合同协议号必须填写公司与客户签订的**最终 PO 号**，不得填其他编号；
6. **产品名称**：报关单产品名称尽量用**产品大类名称**（如玩具、宠物玩具），避免过于细化，减少退税审核风险；
7. 报关单核心数据（中文品名）直接来源于**申报要素表**中的中文品名，须提前核对两者一致。

#### 4.2.3 报关资料整理

报关资料按**一柜一单**命名整理，文件名需包含 **SO 号 + 柜号**（示例：`SO[单号]-[柜号]发票.xlsx`），便于后续财务、报关行查阅归档。

## 五、目的港清关（Destination Clearance）

若客户要求我方提供清关资料，需按**整柜产品**整理资料，确保**提单、商业发票、装箱单**三大核心单据信息完全一致，无任何矛盾。

**时间**：清关材料在**货到港前 3–5 天**准备，**到港后 1–3 天**完成（停留过久会产生滞留费用）。

> 清关主体资格与到港/到门限制见 `regulations/<目的国>.md`（Gate A/B/C）。

### 5.1 清关目的港文件（以一般贸易为例）

1. **提单 B/L（正本）**：由货代提供，核对**柜号、封号、货量、毛净重、目的港**等信息；
2. **清关箱单（Packing List）**：按实际装柜情况填写，与提单数据一致，标注品名、规格、数量、毛净重、外箱尺寸、总件数、总毛重、总体积；
3. **清关发票（Commercial Invoice）**：发票金额必须与客户签订的 **PO 合同金额一致**，标注贸易术语、付款方式、产品明细；
4. **辅助资料**：产品检测/认证证书（CPC/ASTM/UN38.3 等）、原产地证（如有客户要求），按客户要求提供。

### 5.2 核心要求

- 所有清关资料的产品名称、数量、规格、柜号/封号需与**提单、报关资料**一致；
- **确认客户全部款项支付完成后再发送提单正本**，在此之前可使用提单副本；
- 资料制作完成后**反复复核**，避免错漏；按客户要求的方式交付（邮件电子版/快递正本），留存交付记录（一般以邮件发送电子版较为常见）。

### 5.3 美国 ISF（进口安全申报）

- ISF 一般**由客户提交**；
- 若客户/客户授权的货代/报关行要求协助提供 ISF 资料，需及时整理**发货人完整信息、货物品名/HS 编码/数量/毛净重**等，确保与报关、提单资料一致；
- ISF 须在**船舶离港前 72 小时**申报；逾期或不准确可能面临每条 ISF **USD 5,000–10,000** 罚款（以官方为准）；ISF 中的 **SCAC 码、提单号**须与 AMS 一致；
- 若需发送邮件，ISF 文件与提单一同作为附件发送（示例信息：HBL、船名航次、MB/L 号、SCAC、AMS 号、ETD、ETA），**内容仅供参考**，实际以船司/客户要求为准。

## 六、出口退税（Export Tax Rebate）

- 退税材料按**柜**单独整理退税资料，**全程和财务沟通**，对应补充他们所需材料；
- 退税资料不仅需基础单证，全程产生的**司机资料、运输资料、产品出库单、入仓单**等所有相关文件均需收集整理，形成**完整证据链**。

### 6.1 退税材料

#### 6.1.1 出口报关单

委托报关行报关放行后，收集报关行发送的全套报关相关材料：**出口报关单原件、放行单、海运舱单、报关委托书**，按柜号归档。

#### 6.1.2 公司内部文件

1. **购销合同**（公司与工厂签订）：产品名称、单位要与报关单一致，合同金额需与实际和工厂签订的采购合同金额一致；
2. **出库单**（工厂提供给公司）：按一柜一单提供，出库产品的品名、数量、单位需与报关单 **1:1 匹配**，且需有**工厂供货方签章 + 公司客户签章**。

#### 6.1.3 增值税发票（工厂开具）

- 发票品名需与最终核定的 **HS 编码、报关单品名一字不差**，且发票必须**完成认证**；
- 核心校对区域：**购货方信息、产品名称/单位/数量、含税单价/金额**，需与采购合同、报关单、出库单所有数据一致；
- 单位须与**报关单中第一单位**一致。

#### 6.1.4 外贸购销资料

与客户签订的外销合同、商业发票、装箱单（可用报关材料中的外贸购销合同、商业发票、装箱单打印盖公章）。**所有涉及数据要与相关文件一致**；对外购销资料的金额要与 **PO（与客户最终签订的合同）金额一致**。

#### 6.1.5 物流资料

提单复印件、订舱单（SO）、《实际装柜清单》、装柜照片（备查）、过磅单（如有）、拖车司机资料。

#### 6.1.6 发票与汇率

- 公司内部按**一柜一票**开票，购买方信息为客户；
- **退税汇率按装柜当月第一个工作日的汇率**计算（若一号是周六日或国家放假日，顺延到工作日）；
- 汇率查看：中国人民银行官网 `https://www.pbc.gov.cn/zhengcehuobisi/125207/125217/125925/index.html`。

### 6.2 收尾

提交退税资料后，主动**跟进财务申报进度**；若税务机关要求补充资料/进行**函调**，第一时间配合提供**全套证据链资料**（合同、验货记录、装柜照片、运输资料等）。

## 常见履约报错速查

| 环节 | 常见错误 | 预防 |
|------|----------|------|
| 下单前 | 未核版权/认证，产品侵权或不合规 | 首次对接产品先核版权 + 认证 |
| 报关 | 报关资料与实装不一致 | 以《实际装柜清单》为准，单单一致 |
| 提单补料 | 重量误差 >5%、SI 未随实装更新 | 过磅后据实修改 SI |
| 装柜 | 未拍齐 9 步照片、问题柜未拒收 | 按 9 步拍照，异常柜拒收留证 |
| 清关 | 三单（提单/发票/箱单）不一致 | 出单前交叉复核 |
| 退税 | 资料不全、汇率取错月份 | 按柜归档，汇率取装柜当月首个工作日 |
