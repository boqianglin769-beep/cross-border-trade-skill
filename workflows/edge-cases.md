# Edge Cases & Special Scenarios Workflow

> 通用特殊场景处理方法论：「方法论通用，方法不通用」。
> 本文件提供适用于所有特殊场景的**通用决策框架**（识别 → 评估 → 方案生成 → 沟通 → 标注 → 审批），每个场景下的**具体操作方法**（如拆柜转运、改用驳船、让客户自提等）仅为示例，须根据实际情况替换。

---

## 0. 通用方法论框架（决策树）

所有特殊场景遵循同一套决策流程，不因场景不同而改变逻辑顺序：

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 识别信号 (Signal Detection)                         │
│  → 从询价信息、货代反馈、工厂沟通、目的国法规中捕捉异常信号    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 影响评估 (Impact Assessment)                        │
│  → 评估对报价基础的影响程度：轻微 / 重大 / 致命               │
│  → 判断是否需要重新询价、重新核实法规、或暂停报价            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 方案生成 (Alternative Generation)                   │
│  → 至少生成 2 个备选方案（含"维持原计划"作为基准）            │
│  → 每个方案须注明：成本变化、时效变化、风险点、适用条件       │
│  → 不得只给客户"不行"，必须提供"可以这样，或者那样"           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 客户沟通 (Client Communication)                    │
│  → 先说明情况（事实），再给出影响（量化），最后提供方案（多选）│
│  → 所有口头沟通须在 24h 内补书面确认（邮件/消息截图留档）     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 5: 报价单标注 (Quotation Annotation)                   │
│  → 在正式报价单中明确标注限制条件、有效期、条款引用            │
│  → 未确认项用 (TBC) 标记，禁止用模糊措辞（如"大概""应该"）   │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 6: 内部审批 (Internal Approval)                         │
│  → 涉及成本变化 >10% 或条款变更 → 必须经 [老板] 书面确认      │
│  → 涉及新客户 / 新目的国 / 新产品类型 → 必须走法规核实门      │
└─────────────────────────────────────────────────────────────┘
```

**核心原则**：
- **方法论通用**：决策树的 6 个步骤适用于所有特殊场景
- **方法不通用**：Step 3 生成的具体方案（拆柜、驳船、自提等）因国家/产品/客户而异，必须一事一议
- **底线**：绝不单方面替客户做决定，必须让客户在知情的前提下选择

## 1. 运输可达性边界

### 1.1 识别信号

| 信号来源 | 具体表现 |
|---------|---------|
| 客户询价 | 收货地址为内陆城市、偏远小镇、岛屿、高山区域 |
| 货代反馈 | "该地址无卡车可达" / "需额外中转" / "道路限高/限宽/限重" |
| OOG 超限货 | 到港后发现目的国无合适低平板车/框架车；内陆桥梁限重 |
| 港口能力 | 目标港口无卸超大件设备的能力（无重型吊机/无足够堆场） |

### 1.2 影响评估

| 等级 | 判定标准 | 处理方式 |
|------|---------|---------|
| 轻微 | 仅需增加短途转运费（如港口→城市 50km） | 直接纳入报价，标注 "Inland trucking included" |
| 重大 | 需特殊车辆（低平板车、框架车）或中转仓拆柜 | 单独列项报价，标注车辆类型和时效延长 |
| 致命 | 无陆路可达，或目的国法规禁止该尺寸货物内陆运输 | **暂停报价**，进入 Step 3 生成替代方案 |

### 1.3 方案生成（示例 — 方法不通用，须替换）

> 以下方案仅为示例，实际操作中须根据目的国基础设施、客户预算、时效要求替换或组合。

| 方案编号 | 方案描述 | 成本变化 | 时效变化 | 风险点 | 适用条件 |
|---------|---------|---------|---------|--------|---------|
| A | **维持原计划**：港口交货，客户自行安排内陆运输 | 基准 | 基准 | 客户可能不具备当地运输资源 | 客户有本地物流经验 |
| B | **拆柜转运**：在目的港拆箱，分批次用普通卡车转运 | +15-25% | +3-7 天 | 多次装卸增加货损风险 | 货物可拆分、客户接受分批到货 |
| C | **改用平板驳船**：若客户地址临河/临海，改用水路驳船 | +10-20% | +5-14 天 | 驳船班次少，受水位/天气影响 | 客户地址有河港/海港接入 |
| D | **就近港口自提**：改发到距离客户最近的可行港口，客户自提 | -5-10%（省内陆费） | 基准 | 客户需自行解决最后一段 | 客户有本地代理或自有车队 |
| E | **保税仓中转**：先进目的国保税仓，再按需分批配送 | +20-35% | +7-21 天 | 仓储费、二次报关 | 客户有多地分销需求 |

### 1.4 客户沟通话术框架

```
事实陈述：
"经与货代核实，您提供的收货地址 [具体地址] 属于 [偏远/限高/无重型卡车可达] 区域，
标准集装箱卡车无法直接送达。"

影响量化：
"若强行运输，可能产生额外费用约 USD [X] 或导致货物滞留港口产生滞港费 USD [Y]/天。"

方案提供（至少 2 个）：
"我们为您准备了以下方案：
A. 到 [最近港口] 港口自提，您安排本地运输，运费可节省约 USD [Z]；
B. 我们安排拆柜后分批转运，预计增加 USD [W]，时效延长 [N] 天；
C. 若您地址临河，可安排驳船直达，增加 USD [V]，时效延长 [M] 天。
请确认您倾向的方案，我们据此更新报价。"
```

### 1.5 报价单标注

```
Delivery Terms: CIF [Port Name] — Port-to-port only
Inland trucking: NOT included (client's scope) / Included via [方案B/C] (see "Alternative Delivery Options" below)
Special Conditions: Address [客户地址] verified with forwarder on [日期]; oversized cargo may require special permit
```

## 2. 产品属性合规突变

### 2.1 识别信号

| 阶段 | 信号 |
|------|------|
| 工厂报价阶段 | 工厂未提供 SDS/MSDS、未确认是否含电池/液体/磁性材料 |
| 货代订舱阶段 | 货代要求补充 "DGR 分类" / "UN 编号" / "MSDS"，否则不接 |
| 海关查验阶段 | 海关归类与工厂申报不一致（如普通机械 → 含危化品部件） |
| 目的国法规 | 目的国突然调整 HS 编码归类或新增准入认证要求 |

### 2.2 影响评估

| 等级 | 判定标准 | 处理方式 |
|------|---------|---------|
| 轻微 | 仅需补充文件（SDS/MSDS/UN38.3 测试报告），无额外费用 | 要求工厂/实验室补件，时效延长 3-7 天 |
| 重大 | 产品需重新归类为危险品，运费翻倍或需特殊包装/标签 | 暂停报价，与工厂、客户、货代三方协商 |
| 致命 | 产品被目的国禁止进口（如含某类化学品、电池超标） | **终止报价**，建议客户改型或换供应商 |

### 2.3 方案生成（示例）

| 方案 | 描述 | 成本变化 | 时效变化 | 风险点 |
|------|------|---------|---------|--------|
| A | 工厂补件：要求工厂提供完整 SDS/MSDS + UN38.3（电池） | +USD 300-800（检测费） | +7-21 天 | 工厂不配合或报告不合格 |
| B | 产品改型：移除/替换合规障碍部件 | 依产品而定 | +15-45 天 | 需重新测试认证 |
| C | 分批发运：合规部分先发，障碍部分另行处理 | +20-40%（分票费） | +10-20 天 | 两次报关，复杂度增加 |
| D | 转运第三国：先进邻国保税仓，再以小批量/拆分方式进入目的国 | +30-60% | +21-45 天 | 法律灰色地带，高风险 |

### 2.4 工厂端预防（报价前必做）

```
工厂询价时必须同步发送《产品属性确认清单》:
□ 产品是否含电池/电芯？（是 → 须 UN38.3 + MSDS）
□ 产品是否含液体/油/润滑剂？（是 → 须 SDS/MSDS + 闪点数据）
□ 产品是否含磁性材料/放射性材料？（是 → 须磁检报告/辐射安全证）
□ 产品是否含粉末/颗粒物？（是 → 须确认是否为危险品/需特殊包装）
□ 产品外包装材质是否含木质/竹质？（是 → 须熏蒸证/IPPC标识）
□ 产品目标出口国是否有特殊认证要求？（如 CE/FCC/SABER/PSE）

工厂回复须以书面形式（微信文字/邮件）留档，口头承诺无效。
```

### 2.5 客户沟通话术框架

```
事实陈述：
"经核实，该产品含 [液体/电池/磁性材料]，根据 [目的国] 海关规定，
须提供 [SDS/UN38.3/磁检报告] 方可正常清关。"

影响量化：
"若按原计划发货，目的港可能面临 [退运/销毁/高额罚款] 风险。
补件预计增加费用 USD [X]，时效延长 [N] 天。"

方案提供：
"建议方案：
A. 由工厂补充 [文件名称]，预计 [N] 天完成；
B. 若工厂无法提供，建议改用 [替代型号/移除该部件]；
C. 如您已有当地清关代理可协助处理，请告知其具体要求。"

底线声明：
"在未确认合规文件齐全前，我们不会安排订舱，这是对双方风险的负责。"
```

## 3. 贸易术语边界

### 3.1 识别信号

| 信号 | 说明 |
|------|------|
| 客户要求 DDP | 客户说"包送货到门"，但目的国法规不允许外国 IOR（如巴西） |
| 客户混淆 CIF/DAP | 客户以为 CIF = 到门，实际上 CIF 只到港 |
| 客户要求 EXW 但期望我方出口报关 | EXW 下卖方不负责出口清关，若客户无中国出口资质则无法操作 |
| 客户要求 DAP 但拒绝提供进口文件 | DAP 下买方仍须负责进口清关，若买方不配合则货物滞留 |

### 3.2 影响评估

术语混淆的致命性取决于目的国法规：

| 目的国类型 | CIF 到港后谁负责 | 我方能否做 DDP | 风险等级 |
|-----------|----------------|--------------|---------|
| 美国 | 客户或其代理（可委托中国货代代理清关） | 可行，但需美国 IOR | 中等 |
| 巴西 | 必须本地 CNPJ+RADAR 主体 | **不可行**（法规禁止外国 IOR） | **致命** |
| 欧盟 | 客户 EORI 号；非欧盟卖家须设实体或委托间接代表 | 可行但门槛高 | 中高 |
| 日本 | 客户委托通关代理 | 可行但复杂 | 中等 |
| 东南亚（新加坡/越南） | 本地进口人 | 部分可行 | 中等 |

### 3.3 方案生成

| 方案 | 适用场景 | 我方责任边界 | 客户责任边界 |
|------|---------|------------|------------|
| **CIF + 推荐本地代理** | 法规禁止外国 IOR（巴西） | 到港 + 提供商业发票/装箱单/提单 | 清关 + 内陆 + 税费 |
| **CIF + 目的国代理包清关** | 客户无清关经验 | 到港 + 推荐代理联系方式 | 委托代理 + 支付代理费 |
| **DAP + 买方配合清关** | 客户有进口资质 | 到门（不含进口税费） | 提供清关文件 + 支付关税 |
| **DDP（仅限可行国家）** | 美国/欧盟等有成熟代理网络 | 全包（含税费） | 提供进口资质文件 |

### 3.4 报价单标注（强制）

```
Trade Terms: [CIF / DAP / EXW / DDP] [Port / Door Address]
Delivery Scope: [明确列出包含项和不包含项]

Example for Brazil:
  Trade Terms: CIF Salvador CFS (Port-to-port)
  Includes: Ocean freight, origin charges, insurance
  Excludes: Brazilian customs clearance, inland trucking, import duties/taxes
  Note: Per IN RFB 1.984/2020, foreign entities cannot act as Importer of Record in Brazil.
         Local clearance must be arranged by the buyer or their appointed Brazilian broker.

Example for USA:
  Trade Terms: DAP 123 Main St, Chicago, IL
  Includes: Ocean freight, origin charges, insurance, inland trucking
  Excludes: US customs duties/taxes, customs brokerage fee (if buyer uses own broker)
```

## 4. 报价时效与条款对齐

### 4.1 识别信号

| 风险点 | 表现 |
|--------|------|
| 货代报价无有效期 | 货代说"这个价格现在有效"，但未书面确认有效期 |
| 货代报价条款模糊 | "海运费大概 USD 1500" / "可能还有额外费" |
| 汇率剧烈波动 | 报价后 3 天内汇率变动 >3%，影响利润 |
| 燃油附加费(BAF)浮动 | 货代报价含 "BAF subject to change" |

### 4.2 核心原则

> **货代怎么写，我们就怎么写；货代没写的，我们标注为 (TBC)。**

### 4.3 报价单条款标注模板

```
Validity of Quotation:
  - This quotation is valid until [Date] (typically 15-30 days from quote date).
  - Ocean freight rates are based on forwarder's written confirmation dated [Date]
    from [Forwarder Name].

Rate Adjustment Clauses (must mirror forwarder's terms exactly):
  □ Fixed rate — no adjustment within validity period
    [If checked]: "Freight rates are fixed for the validity period."
  
  □ Subject to BAF/CAF adjustment
    [If checked]: "Freight rates are subject to BAF/CAF fluctuations per carrier's
                   monthly index. Any increase will be passed through with 48h notice."
  
  □ Subject to GRI (General Rate Increase)
    [If checked]: "Rates are subject to carrier's GRI announcements. If GRI applies,
                   revised rates will be communicated before cargo handover."
  
  □ Subject to peak season surcharge
    [If checked]: "Peak season surcharge may apply during [months]. Current quote
                   excludes PSC; if triggered, surcharge will be added at cost."

Exchange Rate:
  - Based on [Bank of China mid-rate / forwarder's rate / fixed rate X per boss]
  - If rate fluctuates >3% during validity period, price will be recalculated
    and communicated within 24h.

Force Majeure:
  - Quotation excludes costs arising from war, strikes, pandemic, port closure,
    or government actions beyond our control. If such events occur, parties will
    negotiate in good faith.
```

### 4.4 货代报价单审查清单

收到货代报价后，必须逐条确认以下信息是否齐全：

```
□ 报价有效期（明确到日）
□ 费用明细拆分（海运费、THC、CFS、文件费、封条费、其他附加费）
□ 币种（USD / RMB / 目的国货币）
□ 计费单位（CBM / Ton / 柜型 / 票数）
□ 是否含燃油附加费(BAF) / 货币调整费(CAF)
□ 是否有 GRI / 旺季附加费(PSS) / 战争风险附加费(WRS)
□ 是否含起运港费用（报关、拖车、港杂）
□ 是否含目的港费用（THC、拆箱、文件）
□ 超限货(OOG)是否单独报价（不能直接用普通柜价）
□ 船期 / 航程（仅写"大概"不可接受，须写具体船名或周班）
□ 取消/改单费用
□ 超重/超尺罚款条款
```

**若货代未提供上述任一信息 → 标注 (TBC)，不得擅自假设或编造。**

## 5. 货代违约责任

### 5.1 识别信号

| 违约类型 | 表现 |
|---------|------|
| 临时涨价 | 已确认的价格，订舱后货代通知"爆仓涨价" |
| 船期取消 | 已确认的船期，货代通知"船公司取消这班" |
| 隐性收费 | 到货代账单中出现报价单未列明的费用（如"操作费""系统费"） |
| 服务降级 | 承诺的直航变中转、承诺的整柜变拼箱 |

### 5.2 责任判定标准

| 情形 | 我方态度 | 行动 |
|------|---------|------|
| 货代书面报价单明确有效期且条款确定 → 临时变卦 | **追究责任** | 要求货代书面说明原因；若不合理 → 启动备用货代 + 索赔 |
| 货代报价单**未**明确有效期 / 含"subject to change"条款 → 涨价 | **自担风险** | 接受或另寻货代；下次询价时强制要求书面有效期 |
| 不可抗力导致（港口罢工、船公司破产、战争） | **协商分担** | 依据合同 Force Majeure 条款处理；不单独追究货代 |

### 5.3 备用货代机制

```
每个目的国/航线至少维护 2 家货代：
- 主货代：合作时间长、价格优、服务好
- 备用货代：价格略高但响应快、舱位稳定

触发切换条件：
□ 主货代报价有效期 < 7 天（过短）
□ 主货代报价单缺少关键条款（无有效期、无费用拆分）
□ 主货代临时涨价且无法合理解释
□ 主货代连续 2 次船期延误 >7 天

切换流程：
1. 立即向备用货代询价（提供相同货物信息）
2. 对比价格/时效/条款
3. 向 [老板] 书面汇报切换原因和成本差异
4. 获得批准后执行切换
5. 将违约货代记录进《货代评估表》（供年度复盘）
```

## 6. 变更管理与合同约束

### 6.1 识别信号

| 变更类型 | 示例 |
|---------|------|
| 数量变更 | 报价 10 台 → 客户要 50 台（影响柜型：LCL→FCL） |
| 目的地变更 | 发到 Salvador → 改发到 Itajaí（不同港口法规/费用） |
| 交期变更 | 60 天交货 → 客户要求 30 天（工厂产能/排期是否支持） |
| 产品规格变更 | 型号 A → 型号 B（尺寸/重量/HS 编码可能全变） |
| 贸易术语变更 | CIF → DAP（影响报价基础和合规要求） |

### 6.2 变更处理流程

```
Step 1: 冻结原报价
  → 向客户确认："收到变更请求，原报价单 Q-XXXX 暂停执行，待重新核实后更新。"

Step 2: 评估影响范围
  ├─ 数量变更 → 是否改变柜型？（LCL↔FCL 费用差异巨大）
  ├─ 目的地变更 → 新目的地的法规核实（Gate A/B/C 重新走一遍）
  ├─ 交期变更 → 工厂产能 / 货代舱位 / 船期是否支持
  └─ 产品规格变更 → 新产品的合规文件 / HS 编码 / 包装尺寸

Step 3: 多方确认可行性
  ├─ 工厂：产能、交期、新规格报价
  ├─ 货代：新目的港费用、新柜型价格、舱位
  └─ 法规库：新目的地是否需要额外认证/许可

Step 4: 生成新报价单
  → 引用原报价单编号，标注 "Revised due to [变更原因] on [日期]"
  → 明确旧报价单作废

Step 5: 合同条款确认
  → 若已签合同：依据合同中的变更条款处理
  → 若未签合同：新报价单即为新的要约
```

### 6.3 合同约束底线

```
报价单 / 合同中必须明确约定的不可变更项：
□ 产品型号、规格、数量
□ 目的港口 / 交货地址
□ 贸易术语（CIF/DAP/EXW 等）
□ 报价有效期
□ 交货期（起算点和截止点）
□ 付款方式和时间节点
□ 质量标准和验收方式
□ 违约责任（延期、质量问题、数量短缺）

客户单方面变更的处理：
- 在报价有效期内且变更不涉及上述核心项 → 可协商调整
- 超出有效期或涉及核心项变更 → 视为新询价，须重新报价
- 已下单生产后客户要求变更 → 依据合同中的变更/取消条款执行
  （通常：已生产部分不可退，未生产部分可协商；取消订单可能涉及违约金）
```

## 9. 其他边界场景索引（风险提示）

以下场景虽未详细展开，但报价前须 awareness，必要时触发本工作流：

| 场景 | 触发条件 | 快速处理指引 |
|------|---------|------------|
| **汇率突变** | 报价后汇率变动 >3% | 报价单中预设汇率调整条款；变动超阈值时 24h 内通知客户重新议价 |
| **港口罢工/拥堵** | 目的港/起运港出现罢工、塞港 | 关注船公司/货代通知；考虑中转港或改发其他港口 |
| **反倾销税/关税壁垒** | 目的国突然加征反倾销税或调整 HS 编码税率 | 立即查询目的国海关公告；若税率大幅增加 → 暂停报价，与客户协商 |
| **客户信用风险** | 新客户要求赊销 / 老客户拖欠货款 | 查中信保/邓白氏；新客户 30% 定金起；老客户逾期 → 暂停新订单直至结清 |
| **船公司破产/合并** | 订舱的船公司突然破产或被合并 | 立即联系货代改配其他船公司；检查已订舱货物的提单状态 |
| **目的国政治风险** | 目的国发生政变、制裁、外汇管制 | 关注外交部/商务部预警；受制裁国家 → 禁止报价 |
