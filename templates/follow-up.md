## 一、催货代（微信/微信工作号）

### 1.1 初次询价后跟进

```
[货代对接人]，你好！

关于 [产品名称] 到 [目标港口] 的询价，想跟您确认几个细节：

1. 贵司是否接受 [柜型，如 40FR OOG / 40HQ / LCL] 到该港口的订舱？

3. 运费报价是否包含绑扎加固费用？如不含，请单独报一下绑扎方案及费用。
4. 能否提供预计船期和航程？
5. 报价有效期多久？

以上信息请尽量以书面形式（邮件/微信文字）回复，方便我司留档及给客户报价。感谢！
```

## 二、催工厂（微信）

### 2.1 索要产品视频/照片

```
[工厂联系人]，你好！

客户 [客户名称] 想看一下 [产品名称] 的实物视频和照片，重点需要：

1. 产品整体外观（正面、侧面、背面）
2. 产品细节特写（Logo、接口、按键等定制部位）
3. 包装方式（彩盒、外箱）
4. 外箱正侧唛照片
5. 如果是定制化产品，请拍一下定制效果

麻烦今天内发一下，客户催得急。如果文件大，可以发网盘链接。感谢！
```

### 2.2 确认包装数据

```
[工厂联系人]，

为了订舱和报关，请提供以下数据（务必用包装后外尺寸，不是产品裸尺寸）：

- 外箱尺寸：长 × 宽 × 高（mm 或 cm）
- 毛重（G.W.）：____ kg
- 净重（N.W.）：____ kg
- 每箱装量：____ 件/箱
- 总箱数：____ 箱
- 总体积：____ CBM

另外请确认：
- HS 编码是否与之前一致？
- 产品含电池/液体吗？如有，请提供 MSDS/SDS 和 UN38.3 证书。
- 工厂能开多少税点的专票？（13% 还是 10%？）

以上信息请务必准确，关系到运费计算和报关，出错会产生额外费用。感谢！
```

### 2.3 催生产进度

```
[工厂联系人]，

PO 号：[订单号]，产品：[产品名称]，交期：[日期]。

想确认一下目前生产进度：

- 当前完成百分比？
- 预计何时可以完成大货？
- 是否有可能提前完成？
- 如有延迟风险，请提前告知，我们好和客户沟通。

客户比较关注交货时间，麻烦及时更新，谢谢！
```

### 2.4 确认装柜安排

```
[工厂联系人]，

拖车预计 [日期] [时间] 到厂，司机电话：[手机号]，车牌号：[车牌]。

请工厂提前：
1. 按排柜方案备货

3. 准备好装柜人员，避免司机等待
4. 装柜完成后帮忙拍一下装柜照片（空柜、半柜、满柜、封条、柜号）

有问题随时联系我。
```

## 四、客户沟通快速话术

### 4.1 报价有效期说明

```
此报价基于当前运费和汇率，有效期至 [日期]。
受船期、燃油附加费及汇率波动影响，过期后可能需要重新确认。

英文：
This quotation is based on current freight rates and exchange rate, valid until [Date].
Subject to vessel schedule, bunker adjustment, and currency fluctuation. Reconfirmation required after expiry.
```

### 4.2 运费未确认说明

```
目的港部分费用（如 THC、文件费）需与目的港代理确认后最终核算。
目前报价中的目的港费用为预估，实际以到港账单为准，差异部分多退少补。

英文：
Destination charges (THC, documentation, etc.) are subject to final confirmation with our destination agent.
The destination fees in this quotation are estimated; actual charges will be based on the port invoice. Any difference will be adjusted accordingly.
```

### 4.3 OOG 特殊说明

```
本产品为超限货物（OOG），需使用 40FR 框架柜运输。
目的港卸货需具备相应吊装能力，且内陆运输需单独安排低平板拖车及申请超限运输许可。
以上费用和可行性已单独确认，如有变动会及时通知。

英文：
This product is oversized cargo (OOG) requiring 40FR flat rack container.
Discharge port must have adequate crane capacity. Inland transport requires separate arrangement with lowbed trailer and oversize transport permits.
Costs and feasibility have been separately confirmed; you will be notified of any changes.
```

### 4.4 巴西航线特殊说明

```
巴西航线为到港价（CIF [港口]），不含巴西内陆运输。
货物到港后，需由收货人自行安排清关及从港口到最终目的地的拖车。
中国货代无法提供巴西内陆段服务，请提前与当地代理沟通。

英文：
Brazil route is port-only (CIF [Port]), excluding Brazilian inland transport.
Upon arrival, consignee must arrange customs clearance and trucking from port to final destination.
Chinese forwarders cannot provide Brazilian inland services; please liaise with your local agent in advance.
```
