# Template: Freight Forwarder Inquiry (English)

## WhatsApp / Email Inquiry Template

### Template 1: Standard FCL Inquiry

```
Subject: Freight Quotation Request — [Product Name] to [Destination Port]

Hi [Freight Forwarder Name],

Hope you are doing well.

We have a shipment ready for quotation:

**Cargo Details:**
- Product: [Product Name]
- Quantity: [X] units
- Outer carton dimensions: [L] × [W] × [H] mm per unit
- Gross weight per unit: [X] kg
- Total volume: [X] CBM
- Total gross weight: [X] kg
- HS Code: [XXXX.XX]

**Shipping Requirements:**
- Port of loading: [Port, China] (e.g., Shenzhen Yantian)
- Port of discharge: [Port, Country] (e.g., CIF Salvador, Brazil)
- Container type: [20GP / 40GP / 40HQ]
- Preferred shipping month: [Month Year]
- Terms: CIF [Port]

**Please quote the following (itemized):**
1. Origin charges (pickup, export customs, THC)
2. Ocean freight
3. Marine insurance (110% cargo value)
4. Destination charges (THC, documentation)
5. Estimated sailing schedule and transit time
6. Quotation validity period

**Special notes:**
- [If battery/hazmat: This cargo contains [battery type]. Please confirm if your line accepts it and what additional documents are required.]
- [If OOG: This cargo requires 40FR flat rack. Please confirm if [Port] can handle OOG discharge and if lashing is included.]

Please reply with a written quotation by [Date].

Best regards,
[Your Name]
[Company Name]
[Your Title]
```

### Template 2: LCL Inquiry (Must Confirm Separately)

```
Subject: LCL Quotation Request — [Product Name] to [Destination Port]

Hi [Freight Forwarder Name],

We are considering LCL shipment for the following cargo:

**Cargo Details:**
- Product: [Product Name]
- Quantity: [X] units
- Total volume: [X] CBM
- Total gross weight: [X] kg
- HS Code: [XXXX.XX]

**Shipping Requirements:**
- Port of loading: [Port, China]
- Port of discharge: [Port, Country]
- Terms: CIF [Port] CFS
- Preferred shipping month: [Month Year]

**Please confirm AND quote:**
1. Is LCL consolidation available to [Port] for this product type?
2. If yes, itemized costs:
   - Origin charges (warehouse, consolidation, export customs)
   - Ocean freight (LCL rate per CBM or weight)
   - Marine insurance
   - Destination charges (CFS, THC, deconsolidation, documentation)
3. Estimated sailing schedule and transit time
4. Quotation validity

**Important:** We previously experienced an issue where forwarder confirmed the route was available but LCL was not actually operating at the destination port. Please explicitly confirm LCL service availability.

Please reply by [Date].

Best regards,
[Your Name]
```

### Template 3: OOG / Oversized Cargo Inquiry

```
Subject: OOG Quotation — [Product Name] on 40FR to [Destination Port]

Hi [Freight Forwarder Name],

We have an oversized cargo shipment requiring 40FR flat rack container:

**Cargo Specifications:**
- Product: [Product Name]
- Outer packaging dimensions: [L] × [W] × [H] mm (critical — product is oversized)
- Gross weight: [X] kg
- Quantity: [X] units per container
- HS Code: [XXXX.XX]

**Container:**
- Type: 40FR OOG
- Port of loading: [Port, China]
- Port of discharge: [Port, Country]
- Terms: CIF [Port]

**Critical Questions:**
1. Can [Port] handle 40FR OOG discharge? Please confirm crane capacity.
2. Is lashing/securing included in your freight rate? If not, please quote separately.
3. Can you arrange inland delivery from [Port] to [Final Destination]?
   - If yes: quote trucking cost including permits and escort
   - If no: confirm port-only and we will arrange separately
4. Itemized cost breakdown:
   - Origin (pickup, customs, port handling)
   - Ocean freight (OOG surcharge if applicable)
   - Insurance
   - Destination (THC, documentation)
   - Lashing (if not included)
   - Inland trucking (if applicable)
5. Sailing schedule and transit time
6. Free detention period at destination

Please provide written confirmation for all items above.

Best regards,
[Your Name]
```

## Quick Phrases (Copy-Paste)

| Situation | English |
|-----------|---------|
| Request itemized quote | "Please provide an itemized quotation including origin, ocean freight, insurance, and destination charges." |
| Confirm in writing | "Please confirm the above in writing via email for our records." |
| Mark as budget | "For unconfirmed costs, please mark as 'budget / awaiting confirmation'." |
| Urgent follow-up | "This is urgent — our client deadline is [Date]. Please prioritize." |
| Clarify LCL | "Please explicitly confirm whether LCL consolidation is available to [Port] for this product." |
| OOG crane check | "Please confirm if [Port] has crane capacity for 40FR OOG cargo of [weight] kg." |
| Reject verbal quote | "We require written confirmation. Verbal quotes cannot be used for client quotations." |
| Ask for validity | "What is the validity period of this quotation?" |
| Request BAF/CAF | "Please confirm if BAF and CAF surcharges are included or separate." |
