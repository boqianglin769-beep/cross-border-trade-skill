## 附：常见报错速查表

| 错误类型 | 典型场景 | 预防措施 |
|----------|----------|----------|
| 价格报错 | 未确认目的港费用就报价 | 货代书面确认前不填确认价 |
| 体积报错 | 用裸产品尺寸代替包装尺寸 | 必须用外箱尺寸 |
| 汇率报错 | 用了实时汇率但老板定了固定汇率 | 特殊客户先问老板 |
| 条款报错 | CIF 和 DAP 混淆 | 明确到港还是到门 |
| 港名报错 | Itajaí 和 Ilhéus 混淆 | 港口名称逐字核对 |
| 拼箱报错 | 默认整柜能做 = 拼箱能做 | 拼箱单独确认 |
| OOG 报错 | 没确认卸港吊装能力 | 40FR 必须先确认港口能力 |
| 内陆报错 | 巴西报成门到门 | 巴西只能到港，中国货代不做内陆 |
| 税点报错 | 默认 13% 但工厂只能开 10% | 每单确认工厂税点 |
| 船期报错 | 编了一个船期给客户 | 只能报货代确认的船期 |
